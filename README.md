# SGMLToWordDocConvertor
1. To run this application, two files are required to add.
2. footer_table.png and logo.jpg are necessary to be able to run the program.  
3. This application extracts all texts from SGML file and reformat them into a word document.
4. It requires three major input files: 1st SGML file, 2nd SGML file and a csv file that contains a list of documents that should be extracted.
5. The final product of this application is multiple word documents which has been formatted.
6. The most challening part of developing this application is reformating texts extracted into specific word formats exactly like how it is written in a SGML file.
